# Digital-Journal-App

## Project Overview

The Digital Journal App is a web-based journaling application developed using HTML, CSS, and JavaScript. The application allows users to write, organize, and manage personal journal entries while providing additional features such as a calendar view, profile management, and customizable settings.

The project is designed to provide a simple, secure, and user-friendly environment for recording daily thoughts, experiences, goals, and important events.

---

## Objectives

The main objectives of this project are:

* Record daily journal entries.
* Organize personal notes and memories.
* Track activities using a calendar.
* Manage user profile information.
* Customize application settings.
* Improve productivity and self-reflection.

## Application Workflow

### Step 1: Open Dashboard

Users access the homepage through index.html.

### Step 2: Create Journal Entries

Users navigate to journal.html and write daily journal entries.

### Step 3: Save Personal Records

Entries are stored and displayed for future reference.

### Step 4: Use Calendar

Users view important dates and connect journal entries with calendar events.

### Step 5: Manage Profile

Users update personal information through the profile page.

### Step 6: Customize Settings

Users personalize application behavior through the settings page.

## How to Run the Project

### Using VS Code

1. Download or clone the project.
2. Open the project folder in VS Code.
3. Open index.html.
4. Right-click and select "Open with Live Server".
5. The application will launch in your browser.

### Using a Browser

1. Open the project folder.
2. Double-click index.html.
3. The Digital Journal App will start.
